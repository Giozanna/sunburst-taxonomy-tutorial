# 🍄 Taxonomy Sunburst Tutorial

**A step-by-step R tutorial:** go from a QIIME2-style feature table + taxonomy file to an
interactive, shareable sunburst chart of a microbial community — no Krona install required.

> own QIIME2/DADA2 output any time — see the tutorial's last section.

## 🎯 What this shows

Krona charts are a familiar interactive taxonomy visualization in metagenomics, but they're
generated by a command-line tool that hides the data-wrangling step. This tutorial builds the
same kind of chart **natively in R** with every step visible:

1. Parsing QIIME2/SILVA-style semicolon taxonomy strings
2. Reshaping a feature table into a taxonomy-annotated long table
3. Aggregating abundance at every level of the taxonomic hierarchy (the key idea a sunburst needs)
4. Rendering an interactive `plotly` sunburst
5. Exporting it as a single, self-contained HTML file anyone can open — no R, no server
6. *(Bonus)* wrapping it in a minimal Shiny app with a per-sample filter

## 🗂️ What's in this repo

```
data/
  feature_table.csv    Feature_ID (ASV) x Sample read counts
  taxonomy.csv          Feature_ID -> semicolon taxonomy string + confidence score

R/
  00_generate_demo_data.R   builds the simulated demo dataset
  utils.R                   parse_taxonomy() + build_sunburst_df() + color helper

sunburst_tutorial.Rmd   the full narrated walkthrough (knit to HTML)
app.R                    bonus: minimal Shiny app with a sample-selector dropdown
output/                  generated sunburst_demo.html lands here
```

## 🚀 Running it

```r
install.packages(c("dplyr", "tidyr", "readr", "stringr", "purrr", "tibble",
                    "plotly", "htmlwidgets", "shiny", "rmarkdown"))

# regenerate the demo data (optional — the CSVs are already included)
source("R/00_generate_demo_data.R")

# knit the tutorial
rmarkdown::render("sunburst_tutorial.Rmd")

# or launch the bonus Shiny explorer
shiny::runApp()
```

Open `output/sunburst_demo.html` directly in a browser to see the chart without knitting
anything — it's a self-contained file.

## 🔄 Using this with real data

1. Export your feature table and taxonomy from QIIME2 (`qiime tools export`) or your
   DADA2/phyloseq object as two CSVs shaped like `data/feature_table.csv` / `data/taxonomy.csv`.
2. If your taxonomy strings use different rank prefixes or a different number of ranks,
   adjust `parse_taxonomy()` in `R/utils.R`.
3. Everything downstream works unchanged.
